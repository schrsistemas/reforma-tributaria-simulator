# Control plane

The platform is intentionally divided into control plane and domain planes.

## Control plane

Zynkronyx:
- tenant/user context
- navigation
- operational commands
- workflow visibility
- deployment/health information
- integration status

## Domain plane

Reforma Tributária Simulator:
- fiscal rules
- calculations
- scenarios
- credits
- split payment
- fiscal audit trail

This prevents the Control Center from becoming a second tax engine.
